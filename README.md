# NewsHub 📰

NewsHub é um site de notícias moderno e responsivo, com login via **Supabase** e backend em **Node.js + MongoDB**.  
O site permite visualizar artigos, categorias, pesquisar notícias e comentar em artigos.

---

## 📁 Estrutura do Projeto---

## ⚙️ Requisitos

- Node.js >= 18  
- MongoDB Atlas ou local  
- Conta no [Supabase](https://supabase.com/)
